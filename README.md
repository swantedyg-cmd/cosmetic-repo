# Cosmetic site (working name: Solenne)

Next.js 16 + React Three Fiber. Hybrid 3D: the home hero and product viewer are 3D, everything else is regular HTML.

```bash
npm run dev    # http://localhost:3000
npm run build
```

## Added Nov 2026 (branch `atelier-launch`)

- **Engraving atelier** (product page): type up to 12 characters, choose gold foil or etched; the 3D bottle turns to show it on the back of the glass (`three/label.ts` → `createEngravingTexture`, `Engrave` in `three/Bottle.tsx`). Engraving is stored per bag line.
- **Day / Night** switch in the header (`lib/theme.ts`, `ThemeToggle.tsx`): night palette tokens in `globals.css`, `.keep-day` pins dark/orange sections; 3D hero, tour and viewer follow it. Shop gets a Morning / Evening filter and leads with the formulas for the current ritual.
- **Origins globe** on /ingredients (`OriginsGlobe.tsx`, `three/GlobeScene.tsx`); land dots generated by `node scripts/land-dots.mjs`.
- **Recently viewed** strip (shop + product pages) and **Complete your ritual** (bag + product pages, `lib/ritual.ts`).
- **SEO**: metadataBase, canonical URLs, Open Graph cards generated per product (`opengraph-image.tsx`), Product + Organization JSON-LD (no ratings while reviews are samples), `sitemap.xml`, `robots.txt`, bag is noindex.
- **Checkout**: `POST /api/checkout` re-validates the bag against the catalogue and creates a Shopify cart via the Storefront API, then redirects to Shopify's hosted checkout. Without env vars it answers "demo" and the bag says so. To go live: copy `.env.example`, fill the Shopify values, and map each variant in `src/data/shopify.ts`.
- **Accessibility**: skip link, darker caption grey (`--smoke` 4.5:1), 44px quantity buttons, labelled engraving field. Note: white text on the ember button is 3.4:1 — fine for the large pill but below AA for small text; worth a slightly deeper orange if the client agrees.
